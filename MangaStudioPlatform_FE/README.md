# MangaStudioPlatform FE

React + TypeScript + Vite frontend for Manga Studio Platform.

## Setup

Create a local `.env` file:

```env
VITE_API_BASE_URL=your_backend_url
```

Run locally:

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```

## Deploy

This app can be deployed as a static site. Use `npm ci && npm run build` as the build command and `dist` as the publish directory.
